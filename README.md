# langguessr
a tool to identify your geographic location based on the text found on signs around you

[Watch the 8-minute walkthrough](https://www.loom.com/share/06f76f69572a4bbf9fe5d36c8d8f69ca)

________________________________________________________________________________________________________

requires Python 3.12 and Docker. 
how to use:
1. clone the repo
2. create a virtual environment
3. pip install -r requirements.txt
4. docker compose up
5. python app.py
6. open a browser and go to http://localhost:5000 , and click guess. OR curl.exe -d "user_text=your text here" http://localhost:5000/id_text
